# Анонімні звернення в Telegram на Vercel

Бот приймає текст, фото й голосові повідомлення в особистому чаті та надсилає їх адміністратору. Адміністратор отримує звернення в особистому чаті з ботом і вирішує, публікувати його чи відхилити. У дописі немає імені, профілю або позначки про пересилання від автора. Підписи до фото й голосових зберігаються. Фото з альбому публікуються окремими дописами. Усі повідомлення бота українською.

Людину можна впізнати за її голосом, фото або даними, які вона сама вказала в тексті. Бот публікує звернення лише після натискання кнопки «Опублікувати».

## Налаштування

1. Створи бота командою `/newbot` у [@BotFather](https://t.me/BotFather). Додай його до адміністраторів каналу й дозволь публікувати повідомлення.
2. Завантаж вміст цієї папки в Git-репозиторій та імпортуй його у Vercel. Коренем проєкту має бути папка, в якій лежить `api`. Якщо Vercel запитає про фреймворк, обери **Other**.
3. У **Settings → Environment Variables** додай змінні для **Production**.

   | Змінна | Значення |
   | --- | --- |
   | `BOT_TOKEN` | Токен від BotFather |
   | `CHANNEL_ID` | `@назва_каналу` або числовий ID приватного каналу `-100…` |
   | `ADMIN_ID` | Твій числовий Telegram ID (його можна дізнатися за інструкцією нижче) |
   | `WEBHOOK_SECRET` | Секрет, згенерований командою `openssl rand -hex 32` |

4. Розгорни проєкт після додавання змінних. Відкрий `https://ТВІЙ-ДОМЕН/api/telegram` у приватному вікні браузера. Порожня сторінка означає, що маршрут відповідає. Telegram потрібен доступ до виробничої адреси без входу у Vercel.
5. Один раз підключи Telegram до Vercel. У macOS Terminal встав команди нижче, замінивши адресу на свою. Введи той самий токен і секрет, що й у Vercel. Під час введення вони приховані.

   ```zsh
   read -rs 'BOT_TOKEN?Токен бота: '
   printf '\n'
   read -rs 'WEBHOOK_SECRET?Секрет webhook: '
   printf '\n'
   curl --silent --show-error \
     --data-urlencode 'url=https://ТВІЙ-ДОМЕН/api/telegram' \
     --data-urlencode "secret_token=${WEBHOOK_SECRET}" \
     --data-urlencode 'allowed_updates=["message","callback_query"]' \
     --data-urlencode 'max_connections=1' \
     "https://api.telegram.org/bot${BOT_TOKEN}/setWebhook"
   printf '\n'
   unset BOT_TOKEN WEBHOOK_SECRET
   ```

6. Після відповіді з `"ok":true` відкрий бота, натисни **Запустити** та надішли тестовий текст, фото і голосове. Перевір, що звернення спочатку приходять у твій чат із ботом. Натисни «Опублікувати» на одному та «Відхилити» на іншому й перевір канал. Якщо раніше запускав локального бота, зупини його.

## Як дізнатися свій ADMIN_ID

Для нового бота, перш ніж підключити webhook, відкрий свого бота в Telegram і натисни **Запустити**. Потім виконай у macOS Terminal такі команди.

```zsh
read -rs 'BOT_TOKEN?Токен бота: '
printf '\n'
curl --silent --show-error \
  --data-urlencode 'allowed_updates=["message"]' \
  "https://api.telegram.org/bot${BOT_TOKEN}/getUpdates"
printf '\n'
unset BOT_TOKEN
```

Скопіюй число з поля `message.chat.id` у своєму повідомленні `/start`, де `chat.type` дорівнює `private`. Внеси це число у змінну `ADMIN_ID` на Vercel. Якщо ти вже підключив webhook, укажи свій відомий ID або тимчасово від’єднай webhook командою `deleteWebhook` без видалення черги. Після додавання ID повтори кроки 4–5.

Якщо Telegram не підтвердить публікацію після натискання кнопки, перевір канал. За обриву з’єднання звернення могло вже опублікуватися.
